# Bodkalkulator

Samanlikn to bod på bustaden din og sjå kva som faktisk gir best netto — etter meglarkostnader, renter på mellomfinansiering og løpande utgifter.

Laga for deg som sel ein bustad samstundes som du kjøper ein ny, og treng å vite om eit lågare bod med tidleg overtaking slår eit høgare bod med sein overtaking.

**[Prøv kalkulatoren](https://petrepa.com/bodkalkulator/)**
